# Набор инструментов русификации Witch's Apocalyptic Journey

Игра: Unity 6000.0.46f1, Addressables 2.4.6, пакет Unity Localization.
Официальные языки: zh-CN, zh-Hant, en, ja, ko. Русский кладётся **в английский слот**
(в игре нужно выбрать язык English).

## Где лежит текст игры

| Что | Где | Формат |
| --- | --- | --- |
| Интерфейс (кнопки, меню, подсказки) | `aa/Sta...s64/localization-string-tables-english(en)_assets_all.bundle`<br> | StringTable (MonoBehaviour), ключ — `m_Id`<br> |
| Диалоги, карты, реликвии, события и пр. | `aa/Sta...s64/dataconfig_assets_dataconfigs/text/*.bundle`<br> | TextAsset с CSV; русский пишется в колонки `*_en`<br> |
| Каталог ресурсов | `aa/catalog.bin`<br> | бинарный каталог Addressables; CRC изменённых бандлов зануляется **точечно** (`tools/patch_catalog_crc.py`)

 |

Шрифты трогать **не нужно**: в fallback-цепочке основного шрифта уже есть кириллица
(HarmonyOS Sans JP/TC SDF).

## Конвейер (Рабочий процесс)

Требуется Python 3.10+ и `pip install -r requirements.txt`.
Работает и на Linux, и на Windows.

Весь текст хранится в единой локальной базе данных SQLite (`workspace/translations.db`).

Путь указывается до главной папки игры, в которой находится папка `Witch's Apocalyptic Journey_Data`

```bash
cd tools

# 1. Первичная инициализация (один раз): вытащить готовый перевод из старого патча в БД
python sync_db.py init --patch "путь к патчу" --game "путь к оригинальной игре"

# 2. Синхронизация с игрой: найти новые строки, подтянуть оригиналы и разметить статусы
python sync_db.py sync --game "путь к оригинальной игре"

# 3. Работа с текстом: запуск локальной CAT-панели переводчика (веб-интерфейс)
python preview_app.py

# 4. Сборка патча напрямую из базы данных
python build_patch.py "путь к оригинальной игре"

```

## Работа переводчика

Редактирование текста происходит в удобном веб-интерфейсе.
Запустите `python preview_app.py` и откройте в браузере `[http://127.0.0.1:5000/](http://127.0.0.1:5000/)`.

Интерфейс предоставляет полный контекст (китайский оригинал, английский текст, ключи и ID) и поддерживает:

* Построчный перевод с автоматическим переходом.
* Глобальный поиск по всем бандлам и языкам (с возможностью фильтрации).
* Режим "Search & Replace" для последовательного редактирования результатов поиска.
* Подсветку игровых переменных (`{переменная}`) и отслеживание отсутствующих ключей.

Статусы строк в БД:

* **OK** — перевод готов и сохранен.


* **CHECK** — перенесено из старых файлов, но без кириллицы (возможно, не было переведено).


* **STALE** — китайский оригинал изменился с прошлой версии, перевод стоит перечитать.


* **NEW** — новая строка, перевода нет (в игре пока останется английской).



## При обновлении игры

Имена текстовых бандлов меняются с каждым обновлением. При выходе новой версии игры вам не нужно пересобирать базу с нуля.

Достаточно запустить:
`python sync_db.py sync --game [путь_к_ОБНОВЛЕННОЙ_игре]`

Скрипт автоматически просканирует новые игровые архивы, добавит новые строки со статусом **NEW** и пометит как **STALE** те строки, где разработчики изменили китайский оригинал. Ваш существующий перевод при этом никуда не пропадет. После этого можно открывать `preview_app.py` и переводить новые строки.

## Результат сборки

`dist/RUS-patch/` — готовый русификатор: изменённые бандлы (имена файлов те же,
что у оригинала), `README.txt` и `install.bat` (делает резервную копию и
копирует файлы в папку игры). Для распространения достаточно заархивировать
содержимое этой папки.

**Про catalog.bin.** Проверка CRC бандлов в игре включена (в логе:
`CRC Mismatch ... Will not load AssetBundle`), поэтому каталог патчить необходимо.
Но полная пересборка каталога утилитой AddressablesTools `patchcrc` портит
не-ASCII строки (пути с иероглифами → `?????`, ASCII перекодируется в UTF-16) —
игра вылетает при загрузке ассетов. Поэтому CRC зануляется **хирургически**:
`tools/patch_catalog_crc.py` находит бинарную запись AssetBundleRequestOptions
каждого изменённого бандла (по 32-символьному hex-имени, хешу из имени файла и
размеру оригинала) и переписывает только 4 байта CRC. Итог: в каталоге меняется
ровно 4 × N байт, всё остальное байт-в-байт как в оригинале. Правильность
подтверждена: занулённый CRC `eventlist` (f8d30e36) совпал со значением из
лога игры.
